# 压力测试方法速查表

## Layer4 速查

| 方法 | 消耗类型 | 适用场景 | 观察指标 |
|------|---------|---------|---------|
| SYN | 半连接队列 | 测防火墙/tcp栈 | SYN_RECV数、丢包率 |
| TCP | 文件描述符/conntrack | 测连接表容量 | 连接拒绝率 |
| PTCP/ATCP | 变体绕过检测 | 中间盒穿透 | 过滤命中率 |
| UDP | 带宽 | 测清洗牵引能力 | 入口带宽水位 |
| UDPRAND | 带宽+特征随机 | 绕固定特征过滤 | 清洗延迟 |
| DNS放大 | 反射流量 | 测伪造源处置 | 上游丢包 |
| OVH | 针对高防链路 | 法国机房专项 | 触发清洗阈值 |

## Layer7 速查

| 方法 | 消耗类型 | 适用场景 | 观察指标 |
|------|---------|---------|---------|
| HTTP | Web worker | 测QPS承载 | 响应时间、5xx率 |
| HTTPS | TLS计算+worker | 测握手性能 | 握手失败率 |
| HTTPMIX | 混合路径 | 绕URL限速 | 各路径延迟差 |
| TLS | 握手计算 | 测证书/CPU | CPU软中断 |
| CLOUD | CDN→源站链路 | 测回源保护 | 缓存命中变化 |
| CPU | 动态渲染 | 测应用层高成本路径 | 数据库活跃连接 |
| GOD | 综合极限 | 摸整体水位 | 全链路拐点 |

## 组合测试建议

1. **先单项后混合**：单独跑每个方法确定各层阈值，再模拟真实混合比例
2. **记录拐点而非峰值**：性能开始劣化的点比崩溃点更有运维价值
3. **对照基线**：压测前先采集正常时段的延迟分布

完整方法实测与环境见 [zerodawnsec.com](https://zerodawnsec.com/all-methods.html)。
